The platform

Everything a workshop actually runs on, and nothing it doesn't.

Mzalendo is deliberately narrow. It covers the five things that decide whether a plant makes money this month, connects them properly, and refuses to become a general-purpose ERP that nobody has time to fill in.

{# ── The Pulse ── #}

Manufacturing Pulse

One score, five subsystems, and the reason it moved.

Each subsystem is scored from live records, then weighted by how fast it can stop a plant. A run that has slipped hurts more than a supplier who was two days late, so the weighting says so.

The same four keys on every screen

0
Go back one step
00
Go to the main menu
98
See the next page of a long list
99
Stop and close the session

These are the keys Kenyan services already use, so nobody has to learn ours. They work on every screen. On a screen that asks for a number, 0 still means back — so you cannot type 0 as a quantity, which is not a useful thing to report anyway.

Workers can also just text the shortcode. TASKS, STOCK, IN, OUT and DOWN all work without opening a menu at all.
