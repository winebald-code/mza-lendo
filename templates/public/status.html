What each one means

USSD line is the shortcode workers dial. If it is down the floor cannot report, and entries made during the outage are simply not made, nothing queues on a feature phone.

Outbound SMS is alerts leaving the system. If it is limited, the plant record is still complete and the dashboard still shows everything; only the pushed messages stop.

Database is the plant record itself. If it is down the dashboard will not load, and this page would be showing red rather than loading at all.

Encrypted transport is HTTPS with HSTS. Anything other than operational here means the deployment is not enforcing it, which is a configuration matter rather than an outage.

If something is wrong

The USSD line depends on the mobile network as well as on us, so a fault can sit on either side. Before reporting one, have a worker dial the shortcode from a second network if you can, it tells us immediately which half to look at.

Report outages to info@winebald.tech with the plant name, the time, and what the handset showed. There is a machine-readable version of this page at /healthz if you want to poll it.
